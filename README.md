# PHP4 网页编程入门

🔗 原课程：
[https://stahe.github.io/zh-progphp-nov-2002/](https://stahe.github.io/zh-progphp-nov-2002/)

## 概述

本仓库包含 **关于 PHP4 网页编程的教学资料**。
这是一份旨在辅助教学的教学文档，并非完整的课程。

该文档帮助学生了解 PHP 网页编程的基础知识，并为他们的练习和实验提供资源。

## 文档来源

本材料直接源自课程 **“Java Web 编程入门”**。
教学结构得以保留，但示例和解决方案已**调整为PHP版本**。

因此，对于熟悉**Java和PHP**的读者而言，可以对比：

* Java解决方案
* PHP解决方案

针对**同一Web编程问题**。

## 学习目标

本资源旨在：
* 介绍服务器端Web编程的基础知识
* 展示具体的PHP代码示例
* 为学生提供实践基础
* 促进Java与PHP之间的教学比较
